FBG OptiSense Studio 一号机客户版

安装条件：
1. Windows 10/11 64 位。
2. 已安装 Python 3.12 64 位；安装 Python 时请勾选 Add Python to PATH。

安装方法：
1. 完整解压本安装包，不能直接在压缩包内运行。
2. 双击“安装一号机软件.bat”。
3. 安装完成后，双击桌面的“FBG OptiSense Studio（一号机）”。

随包数据：
- 一号机 2001 点标定表。
- 一号机 9 峰/45 点与 3 峰/15 点记录，默认载入 9 峰版本。
- 一号机 OTA 地址和固件 1.0.86。
- OTA 密码首次输入后由 Windows 当前账户加密保存。

更新说明：
- 客户记录保存在 %LOCALAPPDATA%\FBGOptiSenseStudio，不在程序目录内。
- 后续版本可远程运行新版安装包；旧版目录保留，可用于回退。
- 不要把本机的 OTA 密码文件复制给其他 Windows 账户。
