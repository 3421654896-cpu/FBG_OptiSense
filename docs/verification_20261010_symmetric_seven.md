# 自动每峰七点对称选点：实现与离线验证

日期：2026-10-10。用户要求沿用当前自动选点逻辑，每峰自动选七点，保证左右点位对称。

2026-10-11后续变更：下文固定约1 nm包络、波长镜像属于初版历史实现；固定峰顶−5 dB高度配对也已被最新规则替代。按用户确认，自动选点已改为默认Makima拟合后，在dBm视觉上半段按均匀高度选七个真实点，最低一对锚定半高线上方最近采样点，左右按拟合光强高度配对、不要求波长等距，详见[当前Beta说明](beta_20261011.md)。原七点协议、固件与历史验收记录不变。

## 实现范围

- 峰检测保持原突出度至少5 dB、平滑定位和九峰排序规则。每峰仍在约1 nm包络内取点。
- 每峰选一个密集谱峰顶中心，以及左右三对真实采样点；九峰共63点。严格采用中心物理索引±同一偏移，不再独立舍入左右点。
- 优先靠近原包络等分位置；0.04 nm等间隔密集谱典型偏移为±0.16、±0.32、±0.48 nm。采样步长或可用点不同，偏移可不同，但三对必须镜像且全部来自当前已采密集谱。扫描边缘或点数不足则报错，保留上一条路线，不悄悄生成不对称路线。
- 对称依据2001点表的目标波长。实测标定坐标仍原样保存，配对中点的微小实际波长误差记录在`symmetry_checks`；不能宣称真实光学中心绝对无误差。真实ADC左右高度也不会被强制改成相等。
- 自动生成的七点计划加载时复核镜像索引。手动微调后的计划为手动路线，不冒称自动对称。
- 绘图、Makima拟合、参考线、逐点等待、保存/恢复、手动撤销接续全部支持完整七点。旧45点记录、工厂五点路线和旧手动选点兼容保留；45点训练模型/隐藏3D研发功能未重新训练或转换。
- 参考线继续10 ms/点单次原始ADC、不做光学稳定/峰形筛选；63点纯等待预算为0.63 s，仍另有DAC/处理/传输开销。实时默认每点总等待850 µs，跨峰不叠加。

## 配套固件候选 v1.0.113

- 新协议v6 `T7S!` 支持1～9峰×7点；仍使用808字节控制命令，不改变USB/LAN命令组包长度。
- 每行以98位无损存放物理索引11位、五路DAC分别16/16/15/15/15位、25 µs单位的逐点等待10位。按现有安全边界，编码不会截断或降低DAC精度。
- CRC覆盖前796字节，CRC位于796～799，800～807及行后填充须为零。完整CRC、身份、点数、所有电流/等待/顺序边界均通过后才发布解析结果；不存在未完成校验的DAC写入。
- GAIN/SOA上限145 mA、其余原电流上限、非选中通道反馈检查、停光ACK、40°C共用温控、故障关光保留；无Flash表写入或隐藏路径点。
- 采集数组扩容至63，七点流一律32位点时间戳，避免沿用45点窄时间戳预算导致溢出停止。CH1仍使用原CH1状态编码，其余通道正确记录通道与挡位。
- 老v3/v4/v5命令格式和CRC偏移不变。LAN七点流走现有原始RAW回退，未宣称63点已通过无线吞吐实测。
- 初次源码实现阶段，三号机仍运行上一阶段已烧入的v1.0.112；该阶段没有访问串口/SWD、烧录、开光、重启或改变机器校准参数。旧板卡不能实采新七点协议，必须升级配套固件；不能把旧板的协议拒绝当成七点验收成功。后续用户授权USB升级的结果见下文。
