# 三号机v1.0.118带光诊断

随后用户要求删除2 pm阈值，并将本轮验收范围改为DAC写入与数据传输，不再对照光学准确度。当前中心偏差只报告数值，不按pm大小判定通过/失败；本页以下内容保留首次带光对照的历史事实和当时阈值，不改写原始记录。最新范围与结果见 [DAC与USB传输检查](verification_20261012_dac_usb_transport.md)。

2026-10-12用户明确允许短时开光对照，确认光纤及手指传感器保持静止、不按压。核对原生USB COM18 / 207933893232，固件v1.0.118、启动标识4144503628；测试前后均相同，未重新烧录。

## 方法及范围

使用三号机保存的`last_45_session.json`：实际为9峰×7点，共63点，CH0、5 kΩ。保存设置未使用逐点表，峰内/跨峰均850 µs。本次不改保存路线、采谱参数、等待表、温控目标、拟合算法、界面或客户更新包。

当前已恢复原五路独立HAL写入，不再启用v117/v119寄存器轮询候选或GAIN/SOA合并写入。因此本次是当前采集链路诊断，不是证明已淘汰DAC提速方式的光学合格。

在进行850 µs对照前，先采用每点15 ms的临时慢参考验证采样方式：旧双ADC/原五路 → 单次ADC/原五路 → 旧双ADC/原五路。每组32帧，前16帧预热，每次结束独立确认停采和关光。慢参考仅用于本次测量，没有应用到用户设置。

工程对照沿用已有离线标准：全部63点、全部预热后帧，原始波形允许偏差5%（最低5码）、参考变化1%（最低5码）、拟合中心相对一致性2 pm。该5码下限属于此独立工程对照工具，不是用户已要求去掉下限的90%稳定时间算法；本次不修改任何阈值。

## 结果

三个采集均完整，各32帧，共96帧；I2C/SPI错误均0，温度遥测无故障，停采和关光ACK全部确认。最后再独立核对安全停止、关光和运行版本，串口已释放。

| 采集 | 板温范围 | 停采/关光 |
| --- | --- | --- |
| 前慢参考（双ADC） | 31.4687～32.9609°C | 确认 |
| 中间慢参考（单ADC） | 33.1054～35.1367°C | 确认 |
| 后慢参考（双ADC） | 35.2460～36.6367°C | 确认 |

采样方式资格检查未通过。前后相同双ADC参考的最大拟合中心漂移约43.924 pm，已远超2 pm标准；参考自身还存在波形变化、帧间散布和峰形警告。单次慢参考相对双ADC参考的最大中心差约44.256 pm；由于基准自身漂移，这不是可直接归因于单次ADC或固件的误差。

这不是绝对波长计校验，没有可用依据判断绝对波长精度；也不能把参考异常直接说成固件故障。温度随测量上升约5.17°C是实测现象，可能与光源预热/漂移有关，但未通过受控实验确认因果。传感器静止不等于光学参考一定稳定。

基准检查失败后按既有安全流程停止，不继续850 µs候选、不进行更短等待扫描、不应用或推荐任何新等待。这不表示850 µs已测得不合格：本轮尚未完成它与有效慢参考的对照。
